# 方法、指标与边界

这是一套限定于 **Qwen3-1.7B、28 层等宽 MLP、单 NVIDIA GPU** 的教学与实验工具。已测环境是 Windows x64、Python 3.12、RTX 4060 Laptop 8GB；不承诺任意模型或任意硬件均可直接运行。CPU 单元测试独立于真实 GPU 实验。

## 剪的是什么

MLP 的 gate/up 投影各产生一组中间通道，经过 `SiLU(gate) × up` 后再由 down 投影合并。删除一个通道时，同时删除 gate/up 对应行、down 对应列。残差宽度、注意力和 tokenizer 保留。实际得到更窄的密集矩阵，不是把原矩阵权重置零。

比较两种评分：三个投影的联合权重平方幅值；以及校准激活 RMS 乘 down 对应列的平均绝对权重。后者观察的是 down 的输入。有效 token 的平方和与观察数分别累计，padding 不计数，再计算 `RMS = sqrt(sum(z²) / count)`。64 段各 256 token，每层共观察 16,384 次。

每层 6144→5888 删除 4.17% 的中间通道，全模型参数减少 **2.56%**；6144→5632 对应全模型减少 5.12%。中间通道比例不能当整个模型压缩比例。校准公式只借鉴 FLAP 的评分形式，方法差异见[来源](../THIRD_PARTY_NOTICES.md)。

## 数据与三把尺子

固定 CMRC2018 公开 train/dev 源提交；按标题及规范化资料分组去重，同组只进入一个用途。恢复 512 题（433 组），validation 100 题（99 组），final 200 题（177 组）；另有校准和开发检查。完整提示超过 448 token 或答案超过 63 token 的样本排除并记录，禁止静默截断参考答案。因此结果属于长度筛选后的本地子集。不能保证所有语义近重复或预训练污染已排除。

- **EM**：生成答案是否完全符合参考答案，使用官方脚本规定的标点处理。例如多写一句解释也可能丢分。
- **F1**：预测与参考答案有多少共同内容。这里严格使用 CMRC 官方的最长连续公共 token 片段公式；不是教学版字符计数公式。数字越大越好，但内容重合仍不能证明事实正确。
- **PPL**：模型预测固定文本时的困惑度，可理解为对下一个 token 的不确定程度。相同文本、tokenizer 和计算方法下，越低越好。按 NLL 的有效目标数加权再取指数，不能把各段 PPL 直接平均。

QA 非思考、贪心、batch=1，最多生成 64 token，完整答案只做 strip；命中上限的数量也报告。PPL 窗口 512、步长 256，文档独立，每个有效目标只计一次；validation 8192、final 16384 个目标。两项工程门槛为相对同 split 原模型 F1 下降≤5 个百分点、PPL 增加≤10%。这是事先指定的筛选门槛，不是行业标准或统计显著性。

## 恢复训练与公平对照

剪后与未剪原模型都从干净 base 初始化新的 LoRA，仅 84 个 MLP 投影参加；rank=8、alpha=16、dropout=0.05、学习率 1e-4、AdamW、梯度裁剪 1。base BF16 冻结，adapter FP32。每次 1 题、累积 8 题、64 次更新，512 题只过一遍，共 6762 个答案/EOS 监督 token；累积按有效 token 数加权，非对每题 loss 简单平均。

保存 16/32/64 步，连同 step0 按 validation F1 最高、PPL 最低、步数最早选优；同时要求数值门槛，并保留定性复核。实际两边均选 64。记录者提供的复核笔记不等于自动验证其阅读或事实正确性，助手复核也不等于独立人工验收。

## 合并、最终检验与资源

合并计算 `W_new = W + (alpha/r) × B × A`，按 PEFT 的 BF16 算术舍入。合并前后浮点计算路径不同，回答可能改变，因此重新评测实际导出的完整模型。导出审计检查 84 个目标矩阵、其余参数未变、保存重载哈希与 8 个恢复资料探针；探针不能证明所有输入完全等价。

四个产物和源码先冻结，再分别运行 validation/final：原0、剪后0、原64合并、剪后64合并。final 不用于再选步数、追加训练或放宽门槛。报告同预算原64对照，避免把训练本身带来的收益都算给剪枝。

速度采用两轮独立进程、四模型正序/反序，128/512 输入、固定 32 输出、batch=1、预热2次、重复7次。首 token 排除分词和加载时间；后31 token 速率包含 Python 控制开销。显存区分 allocated/reserved，均不同于整卡占用。两轮方向不一致或范围重叠，就不宣称稳定加速；这仍不是统计显著性检验。

原模型快照与合并保存对 tied embedding/lm_head 的序列化不同。文件体积下降可能包含共享权重去重，不能全归因于剪枝；应同时看去重参数、张量字节与文件字节。

## 可复现性的范围

源码、原始数据、模型、tokenizer、策略与报告通过 SHA256 绑定。公开 `reports/` 是去除本机路径后的派生摘要，附原报告 SHA；它不是能直接输入严格比较器的原始报告。完整运行会在自己的路径下重新生成记录，不要编辑旧 JSON 伪装成原 SHA。

单机、一个训练种子、有限中文任务不能支持通用能力提升、工业部署达标或稳定加速的广泛结论。后续量化、目标设备和任务约束另立实验；当前没有车载/机载实机部署成果。
